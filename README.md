# 📱 Hub de Atividades | Mobile II

Bem-vindo(a) ao repositório central das minhas atividades práticas da disciplina de **Programação para Dispositivos Móveis II**. 

Este espaço foi criado para documentar minha evolução no desenvolvimento mobile, centralizando todas as atividades construídas ao longo da matéria em um único lugar.

> ⚠️ **Ambiente de Execução (Expo Snack)**
> Todos os projetos e componentes deste repositório foram desenvolvidos e otimizados para rodar diretamente no **[Expo Snack](https://snack.expo.dev/)**. O foco destas atividades é a validação rápida de lógica, componentização e estilização sem a necessidade de builds pesadas locais.

---

## 🛠️ Tecnologias e Conceitos Aplicados

Durante o desenvolvimento destas atividades, estou aprimorando os seguintes fundamentos:
*   **React Native:** Construção de interfaces nativas.
*   **Fundamentos JS/JSX:** Lógica de programação, manipulação de datas, arrays e objetos.
*   **React Hooks:** Gerenciamento de ciclo de vida e estado (principalmente `useState`).
*   **Arquitetura:** Separação de responsabilidades (UI e Lógica), componentização e flexbox.

## 🚀 Como testar os códigos

Como os projetos foram feitos para o ambiente de emulação da Expo, testá-los é muito simples:

1. Acesse o site do [Expo Snack](https://snack.expo.dev/).
2. Crie a mesma estrutura de pastas vista aqui (ex: pasta `src` para os componentes).
3. Copie o conteúdo dos arquivos `.js` deste repositório e cole nos respectivos arquivos do Snack.
4. O emulador web (ou o app Expo Go no seu celular) renderizará o aplicativo instantaneamente.
